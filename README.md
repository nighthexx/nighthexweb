# NIGHT HEX Advanced v6

Flask security-audit dashboard for bounded passive website checks, public RDAP domain lookup, heuristic static source-code review, and downloadable JSON/TXT/PDF reports.

## Deploy to Render
1. Upload the contents of this folder to the root of your GitHub repository (keep `app.py`, `requirements.txt`, `render.yaml`, `templates/`, and `static/` in the repository root).
2. Commit changes and deploy the latest commit in Render.
3. Build command: `pip install -r requirements.txt`
4. Start command: `gunicorn app:app --workers 1 --threads 4 --timeout 45`
5. Health check path: `/healthz`. `FLASK_SECRET_KEY` can be generated by Render; `SCANNER_ACCESS_KEY` is not required.

## Features
- Passive public HTTP checks for HTTPS, response security headers, cookie flags, page/form inventory, and visible password-form hints.
- Public RDAP domain lookup; only public contact data returned by RDAP is shown.
- ZIP source-code static pattern review for potential SQL injection, dynamic execution, hardcoded secrets, weak password hashing, password policy/rate-limit indicators, authentication/session configuration, path traversal sinks, TLS verification, and unsafe HTML sinks.
- Download the current report as JSON, TXT, or PDF.
- Responsive dashboard UI with grouped audit categories.

## Safety and limitations
- Website scanning is bounded and passive: it does not submit forms, follow redirects, guess credentials, execute injection payloads, bypass authentication, or read private files.
- Source ZIPs are not executed. Pattern matches are heuristics and require manual validation; no matches do not prove that code is safe.
- URL scanning cannot inspect backend source code. Upload a source ZIP you are authorized to review for code-level evidence.
- Domain lookup does not bypass RDAP privacy redaction or infer private owner information.
- Upload only code you are authorized to audit. In-memory rate limiting resets on restart; for public production use, add a shared rate limiter and abuse monitoring.
