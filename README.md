# NIGHT HEX Advanced v4

Flask app for bounded passive HTTP security checks, public RDAP domain lookup, and heuristic static source-code review of user-supplied ZIP archives.

## Deploy to Render
1. Upload the contents of this folder to the root of your GitHub repository (keep `app.py`, `requirements.txt`, `render.yaml`, `templates/`, and `static/` in the repository root).
2. In Render, use the existing Blueprint/service and deploy the latest commit.
3. Build command: `pip install -r requirements.txt`
4. Start command: `gunicorn app:app --workers 1 --threads 4 --timeout 45`
5. Health check path: `/healthz`. `FLASK_SECRET_KEY` can be generated by Render; no `SCANNER_ACCESS_KEY` is needed in this version.

## Features / limits
- Website scan checks public HTTP response headers and page/form inventory only; it does not exploit, submit forms, follow redirects, or bypass access controls.
- Domain lookup queries the public RDAP service. It shows only contact information returned publicly; it does not bypass privacy redaction or infer an owner's identity.
- Source audit accepts ZIPs up to 8 MB and scans selected source extensions for common risky patterns. Uploaded code is never executed. Results are heuristic and require manual validation.
- Do not upload projects or source code you are not authorized to review. The source audit is not a complete SAST tool and does not guarantee security.
- Rate limiting is in-memory and resets on restart; for public production use, add a shared rate limiter and abuse monitoring.
