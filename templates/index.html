Domain registration lookup

শুধু পাবলিক RDAP রেকর্ড দেখাবে। গোপন/রেড্যাক্ট করা ব্যক্তিগত তথ্য বাইপাস করা হবে না।

Source Code Audit

নিজের বা অনুমোদিত প্রকল্পের ZIP আপলোড করুন। কোড execute হবে না; SQL query concatenation, দুর্বল password hashing, path traversal, authentication/session configuration এবং hardcoded secret-এর সম্ভাব্য pattern খুঁজবে। এটি static scan—কোড execute হবে না।

গুরুত্বপূর্ণ সীমাবদ্ধতা

URL স্ক্যান থেকে backend source code বা নিশ্চিত মালিকানা জানা যায় না। RDAP-এ registrant তথ্য privacy-protected হলে সেটি এখানে পাওয়া যাবে না। SQL Injection, password guessing, authentication bypass ও path traversal-এর সক্রিয় আক্রমণাত্মক পরীক্ষা এই সংস্করণে চালানো হয় না। Source audit সম্ভাব্য code pattern শনাক্ত করে; false positive হতে পারে এবং প্রতিটি finding হাতে যাচাই করুন।
